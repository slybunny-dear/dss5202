# 三种礼服获取方案的年度比较

功能单位为一名学生一年参加6次正式活动，比较购买新品、购买二手和逐场租赁同款 Love, Bonito Eyka 礼服。金额为新加坡元。报价、寿命、清洗、配送和主动时间均使用参数表所列来源与情景假设。

## 基准结果

|方案|排放 kgCO₂e/年|支出 SGD/年|主动时间 分钟/年|综合分|排名|
|---|---|---|---|---|---|
|二手|4.9191323|60.99|120|0.841229|1|
|新品|4.9191323|72.00|120|0.828092|2|
|租赁|11.3796923|108.00|780|0.518915|3|

购买价格在购入年度完整计入支出；制造、分销和处置按6/26分摊。新品与二手使用相同的清洗、配送和时间设定。租赁包含每次取还的专程交通。

## 原始问卷与AHP

原工作簿包含18条记录，其中17份具有完整的Q8–Q10回答。Q8生成E/C，Q9反向生成E/V，Q10生成C/V。五档回答距中心位置的距离0、1、2对应比率强度1、2、3；反向偏好采用倒数。矩阵使用行几何均值计算权重，并检查主特征向量残差。

全部17份完整矩阵按元素作同权几何聚合。环境、成本和便利性权重分别为0.240973154、0.429536510和0.329490337。RI=0.52、CR≤0.1；个人一致性达标11/17，群体CR=0.005885350。这些权重用于探索性综合评价。逐份回答、比率、权重和CR保存在`ahp_individual.csv`。

## 综合评分与交通敏感性

指标得分为1−年度负担/年度参考值，参考值分别为24 kg CO₂e、360 SGD和1080分钟。综合评分使用上述AHP权重加权求和，计算保留完整精度。

α表示计入租赁的取还交通负担占基准交通负担的比例。交通排放、票价和主动出行时间同比例变化；租金、清洗和交接保持固定，权重保持固定。

- 年度排放（kg CO₂e） = 4.491692308 + 6.888000000 × α
- 年度支出（SGD） = 60.000000000 + 48.000000000 × α
- 年度主动时间（分钟） = 60.000000000 + 720.000000000 × α
- 租赁综合分 = 0.865006510 -0.346091054 × α

|综合评分相等的方案|交通负担归属比例 α|
|---|---|
|租赁与二手|6.8704%|
|租赁与新品|10.6662%|

在本组评分参考值和比例变化设定下，租赁在较低临界值以下排名第一，在两个临界值之间排名第二，在较高临界值以上排名第三；临界值处相应方案得分相同。`transport_scenarios.csv`保留0–1区间及精确交叉点的各项负担、得分和排名。

## 来源与复现

参数及来源见`data/parameters.json`、`data/sources.json`和`evidence/`。原始输入位于`data/raw/`；`run_manifest.json`记录输入与计算代码的哈希。`analysis_summary.json`保存本轮分析的完整汇总值。

在项目根目录运行`python -X utf8 -B code/run.py`重建全部结果，运行`python -X utf8 -B -m unittest discover -s tests -v`执行独立公式、来源和边界检查。
